Each project demonstrates core React concepts like component architecture, custom hooks, state management, event handling, conditional rendering, and responsive UI design.

## 🛠️ Tech Stack & Concepts Covered

- **Frontend Core:** React 19, TypeScript, JavaScript (ES6+), HTML5, CSS3
- **Frameworks & Bundlers:** Vite, Next.js 15, Node.js, npm
- **Routing & State:** React Router, Custom React Hooks (`useState`, `useEffect`, `useMemo`, `useCallback`, `useRef`)
- **Styling & UI:** Custom Vanilla CSS, CSS Variables (Theme tokens), Glassmorphic UI design, Bootstrap 5 / React Bootstrap
- **Web APIs & Libraries:** Web Audio API (programmatic sound generation), `marked`, `DOMPurify`

## 🚀 How to Run Locally

To explore and run any of these applications on your local machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/PayalBute6/React.git
   cd React
   ```

2. **Navigate to the desired project directory:**
   ```bash
   cd CalculatorApp  # Replace with any project folder name listed above
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open your browser and navigate to the local URL output by terminal (typically `http://localhost:5173` or `http://localhost:3000`).
